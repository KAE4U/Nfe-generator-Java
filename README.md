# Nfe GENERATOR WITH JAVA

Java project developed for generating and managing Brazilian Electronic Invoices (NF-e), focusing on object-oriented programming concepts, data generation, and invoice simulation.

## 📚 About the Project

This repository contains a Java-based NF-e generator created as an academic project.
The application simulates the creation of Brazilian electronic invoices using structured classes and organized package architecture.

The project was built to practice:

* Object-Oriented Programming (OOP)
* Java package organization
* Data generation and manipulation
* Invoice modeling
* Software architecture concepts

## 🚀 Technologies Used

* [Java](https://www.java.com?utm_source=chatgpt.com)
* [GitHub](https://github.com?utm_source=chatgpt.com)
* Faker library for random data generation

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/KAE4U/Nfe-generator-Java.git
```

2. Open the project in your preferred IDE:

* IntelliJ IDEA
* Eclipse
* NetBeans

3. Make sure the required dependencies are installed.

4. Run the `Main` class.
